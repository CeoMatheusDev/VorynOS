# Prompts de engenharia do VorynOS

O protocolo normativo para agentes está em [`../../AGENTS.md`](../../AGENTS.md). **Não manter uma segunda cópia de `AGENTS.md` neste diretório.**

- [`engineering-prompt.md`](engineering-prompt.md): contexto de arquitetura e orientação para trabalhos extensos.
- [`start-development.md`](start-development.md): comando de início para incrementos pequenos e verificáveis.

Os prompts são auxiliares; antes de agir, inspecione o estado real do repositório e consulte as especificações em `docs/`. Arquiteturas e formatos mencionados como propostas não devem ser tratados como funcionalidades implementadas.
