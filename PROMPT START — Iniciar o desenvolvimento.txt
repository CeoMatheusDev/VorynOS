# VORYNOS — START DEVELOPMENT

Inicie o desenvolvimento real do VorynOS.

## CONTEXTO

O VorynOS é um sistema operacional independente, desenvolvido do zero, prioritariamente em Zig, com C23 e Assembly quando necessários.

Diretório local desejado:

`/home/matheus/Documentos/ProjectOpenCode/VorynOS`

Repositório remoto pretendido:

`https://github.com/CeoMatheusDev/VorynOS`

Plataforma inicial:

`x86_64 + UEFI + QEMU/OVMF`

Compilador-alvo:

`Zig 0.17.0`

Ambiente principal:

Fedora Linux 44, KDE Plasma, Wayland.

## OBJETIVO DESTA EXECUÇÃO

Estabelecer a fundação técnica do VorynOS e iniciar a implementação funcional do bootloader nativo.

Não desenvolva uma interface gráfica simulada.

Não tente implementar todos os subsistemas simultaneamente.

Comece pelo menor incremento funcional que possa ser compilado e testado.

1. Existência do diretório do projeto.
2. Arquivos existentes.

4. Versão e disponibilidade do Zig.
5. Ferramentas C23 e Assembly.
6. QEMU e firmware OVMF.
7. Configuração necessária para compilar aplicações UEFI.
8. Documentação técnica já existente.

Preserve quaisquer arquivos encontrados.

Não sobrescreva implementações existentes sem avaliar seu conteúdo.

Se não houver acesso ao computador do usuário, declare essa limitação e trabalhe somente no ambiente realmente disponível.

## ETAPA 3 — PRIMEIRA IMPLEMENTAÇÃO

Implemente o VNB — Voryn Native Boot.

Requisitos:

1. Inicialização como aplicação UEFI x86_64.
2. Entrada UEFI válida conforme a ABI aplicável.
3. Saída de diagnóstico verificável.
4. Tratamento correto de erros.
5. Build reproduzível.
6. Execução no QEMU com OVMF.
7. Teste automatizável do resultado.

Objetivo inicial:

Exibir a identificação do VorynOS durante a inicialização.

Caso seja utilizado console UEFI em vez de serial na primeira implementação, documente a diferença e implemente a saída serial como incremento verificável.

Não declare que o kernel já está funcional somente porque o bootloader iniciou.
